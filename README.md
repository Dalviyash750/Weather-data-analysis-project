# 🌦️ Weather Data Analysis using Apache Spark and PySpark

TYBSc IT — Big Data Framework project.

Analyses daily weather records (temperature, rainfall, humidity, wind speed) with **Apache Spark (PySpark)** and presents the results in an interactive **Streamlit** dashboard with **Matplotlib** charts.

> The bundled dataset (`data/weather_data.csv`) is **synthetic** (generated by `src/generate_dataset.py`, 5 cities, 2022–2025, 7,305 rows) and is only meant for demonstration. Replace it with a real dataset in the same format to analyse real weather.

## Features

| Module | What it does |
|---|---|
| 1. Dataset upload | Upload a CSV, preview rows, count missing values |
| 2. Temperature analysis | Average / max / min temperature, monthly trend, hottest & coldest days |
| 3. Rainfall analysis | Total rainfall, wettest months, monthly comparison |
| 4. Humidity & wind | Monthly humidity and wind-speed comparison |
| 5. Visualisation | Line charts, bar charts, time-series trend, summary statistics |
| 6. Dashboard | City and date-range filters, KPI tiles, CSV download |

## Workflow

```
CSV dataset → PySpark (load, clean, aggregate) → pandas (small results) → Matplotlib charts → Streamlit dashboard
```

## Requirements

* Python 3.9+
* **Java 8, 11 or 17** (Spark needs a JVM) — check with `java -version`
* Packages in `requirements.txt`

## Setup & run

```bash
# 1. (optional) create a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

# 2. install packages
pip install -r requirements.txt

# 3a. run the dashboard
streamlit run app.py

# 3b. or run the command-line analysis
python run_analysis.py
python run_analysis.py --city Mumbai
```

To regenerate the sample data: `python src/generate_dataset.py`

### Windows note
If Spark complains about `HADOOP_HOME` / `winutils`, it is only a warning for local CSV work and can be ignored. If Spark cannot find Java, install a JDK and set `JAVA_HOME`.

## Dataset format

```
Date,City,Temperature,Rainfall,Humidity,Wind Speed
2022-01-01,Mumbai,25.0,0.0,60.0,6.3
```

Temperature in °C, rainfall in mm, humidity in %, wind speed in km/h. Column names are matched case-insensitively.

## Scope

This is weather **analysis**, not forecasting. A prediction module (e.g. regression with Spark MLlib) is listed as future work in the report.
